# Type Conversion in C#

## What is Type Conversion?
Type Conversion is the process of converting one data type into another data type.

## Example:

string numberText = "50";

int number = Convert.ToInt32(numberText);

## Explanation:
"50" is a string value.
Convert.ToInt32() converts it into an integer value.

## Common Conversion Methods:

- Convert.ToInt32() : Converts value to integer
- ToString() : Converts value to string
- int.Parse() : Converts string to integer
