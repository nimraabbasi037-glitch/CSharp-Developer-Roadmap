# Data Types in C#

## What is Data Type?
Data type defines what type of data a variable can store.

## Common Data Types:

### int
Stores whole numbers.

Example:
int age = 20;

### string
Stores text values.

Example:
string name = "Nimra";

### double
Stores decimal numbers.

Example:
double marks = 85.5;

### bool
Stores true or false values.

Example:
bool isStudent = true;

## Important Point:
Every variable in C# has a data type that defines the kind of value it can store.
