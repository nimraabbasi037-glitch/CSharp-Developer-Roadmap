# Operators in C#

## What is Operator?
Operator is a symbol used to perform operations on variables and values.

## Arithmetic Operators:

+ Addition
- Subtraction
* Multiplication
/ Division
% Modulus (Remainder)

## Example:

int num1 = 10;
int num2 = 5;

int sum = num1 + num2;

## Important Point:
Operators are used to perform calculations and comparisons in C#.
