# Logical Operators in C#

## Definition

Logical operators are used to combine two or more conditions. The result is always True or False.

## Why do we use Logical Operators?

Logical operators are used when we want to check multiple conditions in a program.

## Logical Operators

| Operator | Meaning |
|----------|---------|
| && | Logical AND |
| || | Logical OR |
| ! | Logical NOT |

## Examples

True && True → True

True && False → False

True || False → True

False || False → False

!True → False

!False → True

## Key Points

- Logical operators combine conditions.
- The result is always True or False.
- They are commonly used with if-else statements.
